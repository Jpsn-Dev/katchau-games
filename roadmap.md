# Roadmap — KaTchau Games

Este documento acompanha as etapas de organização do repositório e da adequação acadêmica do site. As tarefas são marcadas como concluídas somente depois de verificadas.

## 1. Diagnóstico e planejamento

- [x] Identificar a estrutura atual do site e suas principais áreas.
- [x] Registrar as tecnologias utilizadas na versão atual.
- [x] Identificar os materiais de atividades em Linguagem C armazenados no repositório.
- [x] Criar documentação inicial para orientar a leitura do projeto.
- [ ] Conferir integralmente os arquivos compactados das atividades em C.
- [ ] Comparar os requisitos acadêmicos com a implementação atual e validar o plano de adequação.

## 2. Adequação do site aos requisitos acadêmicos

- [ ] Definir a estrutura final de páginas independentes.
- [ ] Reconstruir a apresentação com HTML5, CSS3 externo e JavaScript Vanilla, caso esse seja o formato confirmado pela disciplina.
- [ ] Preservar identidade visual, conteúdo, imagens e funcionalidades existentes.
- [ ] Documentar funcionalidades que precisem ser adaptadas ou que não possam ser mantidas.

## 3. Validação

- [ ] Verificar navegação entre todas as páginas.
- [ ] Testar pesquisa, filtros, ordenação e carrinho demonstrativo.
- [ ] Conferir formulários e canais de contato.
- [ ] Validar responsividade em computador e celular.
- [ ] Executar verificações técnicas adequadas à implementação final.

## 4. Entrega

- [ ] Organizar os arquivos finais e os materiais das disciplinas.
- [ ] Atualizar este README e a documentação com o estado real do projeto.
- [ ] Preparar instruções de execução e apresentação.
- [ ] Revisar o repositório antes da entrega acadêmica.

## Observações

- A versão atualmente documentada do site utiliza React, TypeScript e Vite.
- A documentação não considera a migração para HTML, CSS e JavaScript puros como concluída.
- O catálogo e o carrinho são demonstrativos; não há processamento de pagamentos ou vendas reais.
- Alterações estruturais devem preservar o histórico Git e a integração existente com o Lovable.
