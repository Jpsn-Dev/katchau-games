# Atividades de Linguagem C

Na raiz do repositório existem dois arquivos compactados relacionados às atividades de Linguagem C:

| Arquivo | Descrição identificada pelo nome |
|---|---|
| `Cadastro-de-produtos-listagem-de-estoque-e-reajuste-de-pre-o.zip` | Atividade de cadastro de produtos, listagem de estoque e reajuste de preço. |
| `cadastro-e-login.zip` | Material relacionado a cadastro e login. |

## Recomendações para organização

- Mantenha cada atividade em sua própria pasta quando os arquivos forem extraídos.
- Preserve os arquivos originais enviados ou desenvolvidos para a disciplina.
- Inclua um README dentro de cada atividade com objetivo, funcionalidades, instruções de compilação e exemplos de uso.
- Não misture os fontes em C com o código do site.

## Limite desta documentação

Os arquivos estão armazenados em formato ZIP. O conteúdo interno ainda precisa ser conferido para registrar nomes dos fontes, bibliotecas utilizadas, funcionalidades efetivamente implementadas e comandos corretos de compilação. As descrições acima foram feitas somente a partir dos nomes dos arquivos.
